🛡️ Security & Anti-Raid

/deep-scan

Searches through a user's profile to detect potential raider or nuker risks.

/prune-raid

Selects a timeframe and kicks users who joined within that period.

/security-check

Checks server security risks and recommends possible changes.

/setup-verification

Sets up server verification.

/threat-intel

Displays threat intelligence and other server security information.

/threat-level

Allows administrators to alter the server security level.

🔒 Server Control

/channel lock

Locks the selected channel.

/freeze

Freezes all channels.

/lockdown

Pauses server invites.

/unlockdown

Resumes server invites.

/slowmode-all

Activates slowmode across the server for an administrator-selected duration.

🔨 Moderation

/discipline-list

Displays current timeouts and bans.

/infractions

Examines the selected user's current infractions.

/untimeout

Immediately removes a user's timeout.

/warn

Warns the selected user.

⚙️ Automated Systems

/automated-systems

Displays the currently active automated systems.

/filter-curses

Controls the profanity filter and its intensity.

📊 Monitoring & Information

/system-hud

Displays a system monitoring terminal.

/prefix-commands

Displays all available "!" prefix commands.

📢 Utility

/announce

Creates an embedded announcement with a selectable color, title, and description.

🛡️ Greg Bot Terms of Service

Last updated: September 18, 2026

1. Authorization & Permission

By adding Greg Bot to your Discord server, you grant the bot permission to monitor relevant guild activities, audit logs, public messages, and member profiles as needed for its security and moderation features.

You confirm that you have the necessary administrative permissions or authority to add and configure Greg Bot within the server.

2. Security Scanning & Data Processing

Greg Bot may process information such as Discord user IDs, message patterns, account creation dates, and other information required for automated server security.

Security systems may operate in real time. Detected malicious activity may trigger automated actions such as bans, kicks, or timeouts based on the settings configured by server administrators.

3. Log Retention & Anti-Abuse

Security and logging information may be temporarily cached or retained as necessary for the operation of Greg Bot's security systems.

Greg Bot does not intentionally inspect or store private conversational content outside standard automated security triggers, such as spam detection, blacklisted phrases, or invite links.

4. Limitations of Service

Greg Bot is designed to help protect Discord communities, but no automated security system can guarantee complete protection against every attack or abuse method.

The service is provided on an "as-is" basis. Greg Bot is not responsible for attacks that bypass its security filters, accidental automated lockouts, or threats that remain undetected or unmitigated.
